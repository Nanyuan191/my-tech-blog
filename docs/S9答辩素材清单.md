## 四、拍摄注意事项

1. **顺序**：先推代码 → 等 Actions 绿勾 → 线上确认是新版 → 再开始拍（S9-21/22 顺手在 Actions 页面截）。
2. 截图前 **Ctrl+F5 强刷**，避免拿到旧缓存。
3. 浏览器窗口拉宽一点（≥1280px），黑底 + 代码雨才好看；别用无痕窗口（深色模式已被有意下线，别截到闪黑）。
4. 含密码/密钥的画面一律不拍：改密码页只截空表单；腾讯云控制台注意遮挡金额和手机号。
5. 每张图拍完立刻看一眼地址栏——**没带地址栏的重拍**。
