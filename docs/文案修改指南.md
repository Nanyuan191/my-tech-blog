# 文案修改指南 —— 每句话住在哪里、怎么改、怎么加

> 适用：你想改网站上的任何文字（站名、标语、介绍、页脚……），或者想在某块空白处加一段文字。
> 原则：**前端的一切文字都写在 `.vue` 文件的 `<template>` 里**，找到那行字，改掉即可，不碰任何逻辑。

---

## 一、全站文案地图（每一处文字的「家庭住址」）

打开 VS Code，按 `Ctrl + Shift + F` 全局搜索，比一个个文件翻快得多。

| # | 你在页面上看到的 | 住在哪个文件 | 搜索关键词 |
|---|---|---|---|
| 1 | 浏览器标签页上的标题 | `apps/web/index.html` 第 12 行 | `<title>` |
| 2 | 导航栏左上角的品牌名「我的技术博客」 | `apps/web/src/App.vue` 第 31 行 | `我的技术博客` |
| 3 | 页脚两行（版权 + 技术栈 + CI/CD） | `apps/web/src/App.vue` 第 66~67 行 | `© 2026` |
| 4 | 首页大标题「我的技术博客」 | `apps/web/src/views/HomeView.vue` 第 10 行 | `hero` |
| 5 | 首页副标题「记录开发过程中的思考与实践…」 | `apps/web/src/views/HomeView.vue` 第 11 行 | `hero-sub` |
| 6 | 收藏夹/书签里的小图标 `</>` | `apps/web/public/favicon.svg`（画出来的图形，不是文字） | — |
| 7 | 各页面自己的固定文字（如登录页的「登录」标题） | 对应的 `apps/web/src/views/XxxView.vue` | 搜你想改的那句话 |

### ★ 改站名：一次要改 3 个地方
「我的技术博客」这个名字出现在 **3 个文件**里（标签页标题、导航栏、页脚）。
最省事的做法：

1. VS Code 按 `Ctrl + Shift + F`（全局搜索）
2. 搜索框输入：`我的技术博客`
3. 替换框输入你的新名字（比如：`开发笔记`）
4. 点「全部替换」（会替换 index.html 和 App.vue 里共 4 处）
5. 保存所有文件 → 浏览器刷新就能看到

> 注意：全局替换**只会碰文字**，不会碰代码逻辑，放心用。

## 二、怎么在空白处加一段文字（文本框 + 文本）

### 原理（一句话版）
Vue 模板里写的其实就是**普通 HTML**：
- 一段文字 → `<p>这里是要显示的话</p>`
- 一个带样式的「框」→ `<div class="随便起个名"> ... </div>`，然后在下面 `<style scoped>` 里给这个 class 写样式

### 实操示例：在首页横幅下方加一个「关于我」卡片

**第 1 步**：打开 `apps/web/src/views/HomeView.vue`，找到第 13 行的 `</header>`（hero 横幅的结束标签）。

**第 2 步**：在 `</header>` 的**下一行**，粘贴这一整块（从 `<section>` 到 `</section>`）：

```html
    <!-- 关于我：一段自我介绍卡片 -->
    <section class="about-card">
      <h2>👋 关于我</h2>
      <p>
        你好，我是嘉乐，一名对全栈开发感兴趣的学生。
        这个博客用来记录我学习和做项目过程中的踩坑与思考，
        目前正在运营一个基于 Vue 3 + Express + MySQL 的全栈博客系统。
      </p>
      <p class="about-links">
        GitHub：<a href="https://github.com/Nanyuan191" target="_blank">Nanyuan191</a>
      </p>
    </section>
```

**第 3 步**：滚动到文件最底部 `</style>` 的**上一行**，粘贴这段样式：

```css
/* ---- 关于我卡片 ---- */
.about-card {
  background: var(--bg-card);
  border: 1px solid var(--border-soft);
  border-radius: 14px;
  padding: 22px 26px;
  margin: 0 0 30px;
}
.about-card h2 {
  margin: 0 0 10px;
  font-size: 19px;
  color: var(--text-main);
}
.about-card p {
  margin: 0 0 8px;
  line-height: 1.8;
  color: var(--text-body);
}
.about-links {
  font-size: 13px;
  color: var(--text-muted);
}
.about-links a {
  color: var(--accent);
  text-decoration: none;
}
.about-links a:hover {
  text-decoration: underline;
}
```

**第 4 步**：保存 → 浏览器自动热更新，首页横幅下方就多出一张卡片。文字内容随你改，段落想多几段就多复制几个 `<p>...</p>`。

> ★ 因为所有颜色都用了 `var(--xxx)` 语义变量，这张卡片**深色模式自动适配**，不用额外写任何东西。

## 三、前置网页（落地页）大致想法

先给结论：**不建议做「进站先看引导页」那种真前置页**，建议做「首页升级 + 独立关于页」的组合。理由：

| 方案 | 做法 | 评价 |
|---|---|---|
| A. 真前置页（进站先过一页） | 新增一个全屏欢迎页，点击后才进博客 | ❌ 不推荐：访客（和答辩老师）每次都要多点一下才能看到内容，体验减分；SPA 里做全屏过场也要多写路由逻辑 |
| B. 首页 hero 升级 | 在现有横幅上加一句介绍 + 两个按钮（「阅读文章」「关于我」） | ✅ 成本 30 分钟，首页立刻从「光秃秃列表」变成「有门面的主页」 |
| C. 独立「关于」页面 | 新增 `/about` 路由 + AboutView.vue：自我介绍、技术栈徽章、项目介绍、联系方式 | ✅ 成本 1~2 小时，「介绍作用」由它承担，答辩讲个人项目时也有落点 |

**推荐组合：B + C**。首页负责「漂亮的第一眼」，/about 负责「完整的自我介绍」——两者合起来就是你想要的「前置网页 + 美化」效果，但不多花一步点击。

### B 的具体内容（hero 升级后长这样）
- 大标题下加一行：`你好，我是嘉乐 👋 欢迎来到我的数字花园`
- 横幅右下角两个按钮：`📖 阅读文章`（滚动到文章列表）、`关于我 →`（跳 /about）

### C 的页面结构（AboutView.vue）
1. 头像/标识 + 一句话简介
2. 「我在用什么」：技术栈徽章墙（Vue3 / TypeScript / Node / MySQL / Docker / Nginx…）
3. 「这个博客是怎么建的」：3~4 句讲架构（前端 → API → 数据库 → Docker 部署），配一张简易架构图更佳
4. 「找到我」：GitHub 链接、邮箱

### 红线提醒（和之前装修约定一致）
- 允许：改 `<style>`、改模板静态文字、新增独立组件（AboutView.vue）
- 新增 /about 需要**在 `router/index.ts` 里加一行路由**——这个文件属于已授权例外，改动只加不删
- 不碰：现有页面的 `<script>` 逻辑、接口调用

## 四、验收自查

改完后逐项确认：
- [ ] 浏览器标签页标题变了（说明 index.html 改对）
- [ ] 刷新页面后导航栏、页脚的新名字都变了
- [ ] 手机端（F12 切手机视图）文字没有溢出或换行错乱
- [ ] 点右上角「深色」切一下，新加的卡片颜色正常
- [ ] `npm run build`（在 apps/web 目录）不报错
