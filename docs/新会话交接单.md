## 6. 关键技术事实（不要重新试错）

### 接口契约（实测）
- 列表 `{success, data:Article[], pagination}`，data 直接是数组、**不含 content** → 编辑需单独
  `GET /posts/:slug`（带 token，否则草稿 404）；详情 optionalAuth（匿名草稿 404）。
- 写操作 `POST /posts`、`PUT/DELETE /posts/:id`（requireAuth）；固定路径排在 `/:slug` 前。
- 登录入参 `{username, password}`，返回 `data.accessToken`（2h）+ Cookie。
- **评论 5 接口**（97ad1a9）：`GET/POST /posts/:slug/comments`（公开，POST 游客入 PENDING /
  站长 APPROVED）｜`GET /comments`、`PATCH /comments/:id/status`、`DELETE /comments/:id`（需登录）。
  公开返回不含 email；先审后发；限流 10min/5 条（`trust proxy` 已设 1）。
- ★`auth.isLoggedIn` 是函数，漏括号不报错但绕过登录。

### 踩坑清单（详情见各日 `~/.workbuddy/…/.workbuddy/memory/` 日志）
1. `.dockerignore` 必须有；workspaces 子包无 node_modules；Prisma Client 从 builder 阶段拷。
2. `prisma.config.ts` 存在 → CLI 不读 .env → 首行 `import 'dotenv/config'`；生产迁移自动
   （api 镜像 CMD = `prisma migrate deploy && node dist/server.js`）。
3. ★**body 有背景色会盖住 z-index:-1 的元素** → 解法：`.app{position:relative;z-index:0}`
   建层叠上下文（代码雨排查半天的教训，答辩可讲 CSS 层叠上下文）。
4. `docker compose down -v` 删卷=删库，永远别用；关机安全（数据在命名卷）。
5. Vue 路由参数变化不重建组件 → `watch(() => route.params.slug, …, {immediate:true})`。

### 红线
- 不碰后端业务逻辑与接口契约；改前端后要**重建前端镜像**才在 8080 生效（CI/CD 会自动做）。
- `push-to-github.bat` 是机器专属文件，**别提交进仓库**（已在 .gitignore）。
